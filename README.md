# Map Randomizer

**Рандомайзер карт, времени и погоды** для пользовательских боёв в War Thunder.

Приложение создано специально для закрытого сообщества по аниме _Girls und Panzer_ в игре _War Thunder_ - **Таверна подпольной федерации танководства**. Оно помогает быстро и честно генерировать условия для матчей, поддерживая как стандартные карты игры, так и пользовательские карты из **War Thunder Live (WT Live)** с возможностью быстрого копирования ссылок на скачивание.

---

## Установка и запуск

Для работы программы требуется установленный **Python 3.8+** и библиотека PySide6.

### Способ 1: Автоматический (Рекомендуемый)

В корне проекта находятся готовые скрипты запуска. Они автоматически проверят наличие нужных библиотек и установят их, если потребуется.

- **Для Windows:** запустите файл `run.bat` (двойным кликом).
    
- **Для Linux:** откройте терминал в папке проекта, дайте скрипту права на выполнение (`chmod +x run.sh`) и запустите его (`./run.sh`).

### Способ 2: Ручной

1. **Клонируйте репозиторий** или скачайте проект в виде ZIP-архива.
    
2. **Установите зависимости.** Откройте терминал в корневой папке проекта и выполните команду:  
    pip install -r requirements.txt
    
3. **Запустите приложение.** Из корневой папки проекта введите:  
    python -m app.main

## Как пользоваться

- **Кнопка «Сгенерировать»** (или клавиша `Enter`) — выбирает случайную карту, время и погоду для боя.
    
- **Клик по названиям параметров** (Карта, Время, Погода) — меняет только выбранный параметр, не трогая остальные. Удобно, если нужно перекрутить только погоду.
    
- **Галочка «Карты WT Live»** (в правом нижнем углу) — добавляет пользовательские карты из WT Live в общий пул рандома. Обычные карты при этом не исчезают.
    
- **Копирование ссылок** — если выпала карта из WT Live, её название будет помечено префиксом `wtl |`. Кликните по названию карты, чтобы скопировать ссылку на её скачивание в буфер обмена. В левом нижнем углу появится плавно исчезающее уведомление, а ссылку можно будет вставить в браузер через `Ctrl+V`.

## Кастомизация (Настройка под ивент)

Проект спроектирован так, чтобы вы могли легко менять контент и внешний вид без правки основного кода.

### 1. Изменение списков (файлы в `assets/data/`)

Все данные хранятся в обычных текстовых файлах. Вы можете открыть их в любом блокноте.

- **`maps.txt`** — список стандартных карт. Каждая карта пишется с новой строки.
    
- **`time.txt`** — список времени (например, `12:30`).
    
- **`weather.txt`** — список погоды (например, `Ясно`, `Гроза`).
    
- **`maps_wtlive.txt`** — список карт из WT Live.

**Важные правила для файлов:**

- **Комментарии:** Строки, начинающиеся с `//`, игнорируются программой. Используйте их для группировки.
    
- **Формат WT Live:** Чтобы ссылка корректно копировалась, пишите карту в формате `Название карты | Ссылка`.  
    _Пример:_ `Полигон XXL | https://live.warthunder.ru/dl/...`
    
- В обычных картах символ `|` не используется, пишите просто название.

### 2. Тексты интерфейса (`app/texts.py`)

Если вы хотите изменить название окна, текст кнопок, заголовки или сообщение о копировании, откройте файл `app/texts.py`. Там собраны все строки, которые отображаются в программе.

### 3. Стили и внешний вид (`app/style.qss`)

Внешний вид приложения (цвета, шрифты, прозрачность) настраивается с помощью файла стилей `app/style.qss`, который использует синтаксис, похожий на CSS. Вы можете изменить цвета кнопок, заголовков и чекбоксов, не трогая Python-код.

### 4. Фоновая картинка и её положение

Замените файл `assets/images/image.png` на свое изображение (оставив то же имя). Картинка автоматически применится в качестве фона.

Если картинка расположена не там, где вам нужно, её положение можно настроить в файле **`app/widgets/gradient_image.py`** (в методе `paintEvent`):

- Найдите переменные `offset_x` и `offset_y`. Меняйте их значения, чтобы сдвигать изображение влево/вправо или вверх/вниз.
    
- Там же можно поменять тип масштабирования (например, на `Qt.KeepAspectRatio`, чтобы картинка вписывалась целиком, а не обрезалась по краям).
